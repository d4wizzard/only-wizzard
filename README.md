# Only Wizzard

Eine responsive One-Page-Website für gepflegte Unterhaltung – bereit für GitHub Pages.

## Auf GitHub Pages veröffentlichen

1. Dieses Verzeichnis in ein GitHub-Repository pushen.
2. Im Repository **Settings → Pages** öffnen.
3. Unter **Build and deployment** „Deploy from a branch“ wählen.
4. Branch `main` und Ordner `/ (root)` auswählen und speichern.

Danach ist die Seite unter `https://DEIN-NAME.github.io/REPOSITORY/` erreichbar.
